# Sinclair ZX-81 (`zx81`)

Hardware and Mojave preset notes for the Sinclair ZX-81 (1981 floating-point
BASIC, Ferranti ULA, 1 KiB RAM). Closely related to the ZX-80 but **not** the
same machine — see [zx80.md](zx80.md) for differences.

Own all preset-specific code under `machines/zx81/`, `devices/zx81/` (ULA/video,
display file, character ROM, port decode, RAM mirror), matching tests, and
`frontend/*zx81*`. Shared membrane keyboard, cassette stub, and host-input
helpers live in `devices/sinclair/`. Do not `#include` from `zx80/`, TRS-80, or
other non-family preset folders. `make check` enforces this. ULA, video, and
NMI/INT policy stay per-preset. See [preset-layout.md](../shared/preset-layout.md).

## System overview

| Property | Value |
|----------|-------|
| Manufacturer | Sinclair Research |
| Year | 1981 |
| CPU | Z80 @ 3,250,000 Hz |
| ROM | 8 KiB floating-point BASIC (0x0000 – 0x1FFF) |
| RAM | 1 KiB built-in (0x4000 – 0x43FF) |
| Video | 32×24 text, 256×192 pixels; Ferranti ULA |
| Graphics | 64×48 block graphics (half-resolution cells) |
| Keyboard | 40-key membrane, 8×5 matrix (same PCB family as ZX-80) |
| Storage | Cassette @ ~250 baud (EAR/MIC) |
| Interrupts | **NMI** for SLOW-mode display; maskable **INT** also used in the display path |

### ZX-81 vs ZX-80 (do not mix up)

| Topic | ZX-81 (`zx81`) | ZX-80 (`zx80`) |
|-------|----------------|----------------|
| ROM | 8 KiB | 4 KiB |
| Custom chip | Ferranti ULA | TTL only |
| Display while BASIC runs | **SLOW**: NMI keeps display | Screen blanks |
| Compute without display | **FAST** mode | Always “blank while busy” |
| Interrupts | NMI (SLOW) + display INT | INT for video sync; no NMI SLOW |
| BASIC | Floating-point | Integer |
| System variables | Through ~`0x407C` | 40 bytes (`0x4000`–`0x4027`) |

Implement **ZX-81 behaviour** in this preset. Do not shrink the ROM map to 4 KiB
or omit NMI SLOW mode.

## Memory map (standard 1 KiB machine)

| Address range | Size | Description |
|---------------|------|-------------|
| 0x0000 – 0x1FFF | 8 KiB | ROM (BASIC + character bitmaps) |
| 0x4000 – 0x407C | ~125 B | System variables (`ERR_NR`, `D_FILE`, `CDFLAG`, …) |
| 0x407D – … | variable | BASIC program (grows upward; cold start often starts here) |
| D_FILE – … | variable | Display file (follows the program; pointed by `D_FILE`) |
| … – 0x43FF | remainder | Variables, stacks, free RAM toward top of 1 KiB |

Do **not** copy the ZX-80 “40 byte” sysvar window (`0x4000`–`0x4027`) into this
preset — the ZX-81 system area is larger.

Key system variables (define as contract constants):

| Symbol | Address | Role |
|--------|---------|------|
| `ERR_NR` | 0x4000 | Error code − 1 |
| `D_FILE` | 0x400C | Pointer to display file start |
| `CDFLAG` | 0x403B | FAST/SLOW / compute-and-display flags |

Video fetch mirror (ULA): high-address fetches in the **0xC000 – 0xFFFF** range
map onto RAM and participate in display generation. Document in the contract;
implement with the ULA / video device.

16 KiB RAM pack (common expansion at 0x4000+) is out of scope for the core
`TODO.md` checklist — add only after every core item is done.

## Display file (DFILE)

Variable-length display file in RAM pointed to by `D_FILE` (0x400C). Same
*idea* as the ZX-80, but software names and layout differ — do not copy the
ZX-80 “HALT at the start of every line” wording blindly.

- Byte **`0x76` is NEWLINE** in the ZX-81 display file (same numeric value as
  Z80 `HALT`; the ULA/CPU fetch path still treats it as a halt delimiter).
- **Collapsed** screen (cold start / small RAM): about **25 NEWLINE** bytes
  (minimal 24-line skeleton plus leading delimiter).
- **Expanded** screen: each of 24 rows is up to **32 character codes + one
  NEWLINE** (≈ 33 bytes per row).
- Character codes 0–63 index the ROM bitmap table (8×8 pixels per cell).
  Inverted video uses codes with the inverse bit set (commonly bit 7 on ZX-81).

**32×24 characters → 256×192 pixel framebuffer**.

## ROM character bitmaps

Character patterns live in the 8 KiB ROM (not a separate chargen chip). The
display path uses the Z80 **`I` register** as the high byte of the character
bitmap base — typically **`I = 0x1E`** so glyphs start at **`0x1E00`**.

Decode glyph rows from the **8 KiB** ZX-81 ROM layout. Do not assume ZX-80
4 KiB chargen offsets. Unit-test with known codes using inline ROM bytes.

## ULA video and SLOW / FAST

The Ferranti ULA generates video and drives the SLOW/FAST behaviour:

| Mode | Behaviour |
|------|-----------|
| **FAST** | CPU runs at full speed; display is blank / not maintained while computing |
| **SLOW** | ULA issues **NMI** so the display stays live while BASIC runs (CPU time shared with refresh) |

### Phased implementation

| Phase | Scope | When |
|-------|-------|------|
| **v1 (core)** | 50 Hz frame tick: walk DFILE → 256×192 `Framebuffer`; model FAST blanking and SLOW “display kept” at frame level | ULA video `TODO.md` item |
| **v2 (optional)** | Cycle-accurate ULA fetch/NMI timing, exact SLOW CPU steal | After core checklist |

Ship frame-based rasterization and a correct SLOW/FAST *contract* first. Do not
block the core video item on full ULA cycle accuracy.

Frame rate: **50 Hz** (PAL). Drive from device `tick()`, NMI policy, and
`guest_cpu_clock_hz`.

## RAM mirror / VRAM trap (0xC000+)

High-address instruction fetches in **0xC000 – 0xFFFF** alias onto RAM and feed
the ULA display path. Own this trap under `devices/zx81/` (not `devices/zx80/`).
Document `vram_mirror_start` in the contract; implement in the RAM-mirror
`TODO.md` item.

## Keyboard matrix (40 keys, 8×5)

Same membrane matrix family as the ZX-80. Rows selected by **IN** with one of
address lines **A8–A15** driven low. Five data bits per read; bit clear = key
down (active low).

Standard layout (same PCB matrix as ZX-80):

```
        D4    D3    D2    D1    D0
A8=0    SHIFT Z     X     C     V
A9=0    A     S     D     F     G
A10=0   Q     W     E     R     T
A11=0   1     2     3     4     5
A12=0   0     9     8     7     6
A13=0   P     O     I     U     Y
A14=0   NEWLINE L   K     J     H
A15=0   SPACE .     M     N     B
```

Row select uses port low byte `0xFE` with exactly one of A8–A15 low. Reuse
`SinclairKeyboard` in `devices/sinclair/`. Port decode stays under
`devices/zx81/`. Do **not** invent a `Zx81Keyboard` and do not `#include`
`devices/zx80/`.

The device handles bus/IN semantics only — **no SDL/Qt6 includes**.

ZX key legends differ from PC (`NEWLINE` not Enter, `£` present). Map host
keys in the host layout typing step, not in the matrix device.

## Cassette interface

- **MIC** (output) and **EAR** (input) via port decode shared with the
  keyboard I/O family (`SinclairCassette`).
- Standard speed ≈ **250 baud**.
- Unit-test with bit-level waveform fixtures.

Defer tape image loaders until the device latches work.

2. Display file layout — DFILE parser (NEWLINE/`0x76` lines, 32 cols); tests with inline RAM
3. ROM character bitmap reader — glyph rows from 8 KiB ROM (`I` base, typically `0x1E00`)
4. ULA video — 50 Hz, DFILE → 256×192; FAST blanks, SLOW keeps display via NMI

6. Keyboard matrix — reuse Sinclair family; IN read, row from address high byte
7. Cassette EAR/MIC — idle levels, no image transport
8. Machine clock — 3.25 MHz + NMI for SLOW mode (and display INT as required)
9. Plug into SDL/Qt6 virtual screen
10. Wire keyboard to SDL/Qt6
11. Host layout keyboard typing

## Anti-patterns

| Do not | Do instead |
|--------|------------|
| Reuse `devices/zx80/` via `#include` | Use `devices/sinclair/` for shared membrane/cassette/host-input; keep ULA in `devices/zx81/` |
| Use 4 KiB ROM end (`0x1000`) | 8 KiB ROM end (`0x2000`) |
| Copy ZX-80 40-byte sysvar map | ZX-81 sysvars through ~`0x407C`; include `CDFLAG` |
| Describe DFILE as ZX-80 HALT-prefixed lines only | NEWLINE/`0x76` rows; collapsed ≈ 25 NEWLINEs |
| Ignore SLOW/FAST and NMI | Core ULA + clock items require NMI SLOW (+ display INT) |
| Treat as fixed VRAM like TRS-80 | Variable DFILE via `D_FILE` |
| Invent `Zx81Keyboard` | Reuse `SinclairKeyboard` |
| Bundle ULA + keyboard + SDL in one step | One `TODO.md` checkbox per layer |
| Start with 16 KiB RAM pack | Core 1 KiB machine first |
| Port Spectrum ULA attribute logic | ZX-81 has no Spectrum attribute map |
